# DDOS ATTACK DETECTION & NETWORK TRAFFIC ANALYSIS DASHBOARD

## Project Overview

This project presents an interactive Power BI dashboard for analyzing network traffic and detecting DDoS attacks.

The dashboard uses network traffic data to compare normal and attack traffic and provides visual insights into traffic patterns, attack distribution, and classification performance.

A Random Forest classification approach is used for attack detection.

## Objectives

- Analyze network traffic records.
- Identify DDoS attack traffic.
- Compare BENIGN and DDoS traffic.
- Visualize important network traffic patterns.
- Evaluate the performance of the classification model.
- Present the results through an interactive Power BI dashboard.

## Dashboard Features

- Total Network Records
- Attack Traffic Count
- Attack Percentage
- Normal Traffic Count
- BENIGN vs DDoS traffic distribution
- Destination Port analysis
- Actual vs Predicted classification results
- Precision, Accuracy, F1-Score and Recall
- Random Forest classification

## Dataset

The dashboard is based on network traffic data containing BENIGN and DDoS traffic records.

The data is analyzed and transformed to generate meaningful visualizations and classification results.

## Model Performance

The dashboard reports the following classification metrics:

- Precision: 99.85%
- Accuracy: 99.87%
- F1-Score: 99.87%
- Recall: 99.90%
